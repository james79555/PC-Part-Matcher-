# PC Part Matcher - Agent Rules

These rules are derived from the project's `assignment_spec.txt`. As an AI agent working on this repository, you must prioritize these guidelines to ensure the project meets the highest marking criteria for the Web Design 2 assignment.

## 1. Core Assignment Requirements
Every feature, page, and component you build must contribute to fulfilling the following mandatory requirements:
- **Architecture:** Component-based architecture with shared state.
- **Routing:** Implement a landing page and at least three subpages linked via routing.
- **Design & Styling:** Fully responsive design with global styling configuration. Use BEM and keep naming conventions consistent across the project in line with what i have done previously. 
- **Compliance:** Strict adherence to accessibility (a11y) and GDPR guidelines.
- **Forms:** Include at least one form with robust input validation.
- **API Integration:** Integrate an external API to fetch and display data. This must include at least one search filter (e.g., date range, search bar, category filters, or sorting).

## 2. Additional Deliverables
Keep in mind the broader scope of the project which requires:
- **WordPress Theme:** (Suggested approach: Embedded SPA)
- **WordPress Plugin:** (Suggested approach: Custom REST API Endpoint Plugin)
- **Social Integration:** (Suggested approach: "Share My Build" Feature)

## 3. Code Quality & Marking Criteria Focus (Aiming for 100%)
To achieve the "Excellent" band (32-40 pts per section):
- **Visuals & UX (40%):** Design must be highly professional, visually engaging, tailored to users, and consistent across all pages. Use excellent layout, typography, color, and visual hierarchy. Ensure intuitive and polished user experience.
- **Technical Skills (40%):** Functionality must be robust, polished, responsive, and largely free from bugs/defects.
- **Code Readability (20%):** Code must be exceptionally well-organized, structured, and documented. Use clear and consistent naming conventions. The file structure must demonstrate a strong understanding of professional web development practices.

## 4. Educational & AI Transparency Guidelines
Because this is a university assignment, the user (student) needs to fully understand the code you help them write.
- **Explain Your Work:** Always explain complex logic, architectural decisions, and how new code fits into the overall project.
- **Write Readable Code:** Favour clear, readable, and maintainable code over clever but obscure one-liners.
- **Add Comments:** Provide well-structured comments in the code to explain *why* something is done, not just *what* it does.
- **Encourage Learning:** Do not simply dump massive amounts of code without context. Break down steps so the user can verify, fact-check, and learn from the implementation.
